# Contribución

## Idioma

- Documentación, commits y explicaciones: español de Venezuela.
- Identificadores de código: inglés americano.

## Flujo de trabajo

- Trabajar en ramas pequeñas `dev-<tarea>` cuando el proyecto use git.
- No publicar en `master` sin aprobación explícita del maintainer.
- Cada cambio debe tener validación mínima antes de reportarse como listo.

## Commits

Formato Conventional Commits:

```text
feat(modulo): descripcion imperativa
fix(modulo): descripcion imperativa
docs(modulo): descripcion imperativa
```

No usar `Co-Authored-By` de agentes IA.

## Documentación

Si cambia comportamiento operativo o documentación del repo, actualizar también la ficha/réplica del vault en la misma tarea.
